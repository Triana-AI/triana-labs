## 1. Outcome and authority

Given an immutable accepted case, a versioned user-owned context projection,
the bounded current episode, and the latest target observation, Triana accepts
exactly one policy-authorized user utterance or one structured stop. It rejects
assistant imitation, exact or near assistant copying, hidden-fact leakage,
declared fixed-fact conflict, and unauthorized reactions or actions before a
subsequent target call.

- Deterministic code owns context identity, projection, visibility, allowed
  reaction membership, interaction-state transitions, observation binding,
  semantic hard gates, termination, budgets, custody, denominators, and
  publication.
- The simulator owns wording and may propose one allowed reaction or stop.
- A human owns naturalness, material adaptation, residual semantic-role
  judgment, and the fidelity ruling.
- No model judge, target, or persistent memory creates acceptance truth.

## 2. Versioned user-context migration

LABS-04 artifacts remain immutable. LABS-06 derives a separate closed
`SimulatorCaseContext` that names the original case, persona, intent, and turn
policy identities and hashes. The migration corrects assistant-directed policy
prose into user-owned authority only through explicitly authored fields:

```text
context_id and context_version
source case/persona/intent/turn-policy identities and hashes
persona projection
intent projection
known fact registry
controller-only hidden fact registry and matchers
fixed-fact conflict matchers
user reaction registry
user action registry
stop registry
deterministic state-transition table
assistant-only claim/action matchers
```

Every matcher and transition is human-authored fixture/config authority, never
generated by the evaluated simulator. An ambiguous, incomplete, unknown, or
assistant-owned migration is `SIMULATOR_CONTEXT_INVALID` before simulator or
target egress. The historical artifacts are never edited or replaced.

Known fact text may enter the simulator request. Hidden fact values and their
matchers remain controller-local; the provider sees only hidden fact IDs and
their `HIDDEN` visibility. A hidden fact may become known only through an
explicit deterministic disclosure transition or a declared matcher against an
observed target response. Absence never means disclosed.

## 3. Episode-local interaction state

The state is closed and recreated from the case context for each episode:

```text
patience_level: LOW | MEDIUM | HIGH | UNKNOWN
trust_level: LOW | MEDIUM | HIGH | UNKNOWN
urgency_level: LOW | MEDIUM | HIGH | UNKNOWN
confusion_level: LOW | MEDIUM | HIGH | UNKNOWN
```

The simulator cannot mutate this state. After an accepted `reaction_id`,
deterministic code applies the exact registered transition. Unknown transition,
underflow, undeclared disclosure, or cross-episode input is
`SIMULATOR_CONTEXT_INVALID`. No free-form emotion state or cross-run state
exists.

## 5. Simulator response

The strict response has exactly:

```json
{
  "consumed_observation_hash": "sha256:...",
  "speaker_role": "USER",
  "disposition": "EMIT",
  "reaction_id": "reaction-...",
  "action_ids": [],
  "user_utterance": "one natural user utterance",
  "stop_reason_code": null
}
```

The union rules are:

- `EMIT` requires `speaker_role: USER`, a registered currently allowed
  `reaction_id`, an ordered unique list of currently allowed `action_ids`, one
  nonempty user utterance, and null `stop_reason_code`.
- `STOP` requires `speaker_role: USER`, an allowed stop reaction, null
  `user_utterance`, empty `action_ids`, and a registered nonempty
  `stop_reason_code`.
- The consumed hash must equal the exact latest observation hash.
- Unknown fields, duplicate keys, invalid companions, invalid UTF-8, excessive
  content, controls, or unknown enum values are `SIMULATOR_INVALID_RESPONSE`.
- Binding mismatch remains `ADAPTATION_BINDING_MISMATCH`.

An accepted `STOP` terminates exactly once as `CASE_STOP_CONDITION`, emits no
user transcript row or visible token such as `:done:`, performs no later target
turn, and retains the simulator ledger entry.

## 6. Deterministic semantic validation

Validation occurs after structural and binding validation and before transcript
or state mutation. Rejection uses top-level gap
`SIMULATOR_SEMANTIC_INVALID` plus one sorted unique closed detail-code list:

```text
ROLE_INVERSION
EXACT_ASSISTANT_ECHO
NEAR_ASSISTANT_ECHO
HIDDEN_FACT_LEAK
FIXED_FACT_CONFLICT
UNAUTHORIZED_REACTION
UNAUTHORIZED_ACTION
STOP_NOT_ALLOWED
```

All applicable defects are retained; none is repaired. The original request,
response hash, HTTP exchange, tokens, and reservation remain in the ledger.
No rejected output becomes a transcript turn and no second simulator attempt
or target call occurs for that turn.

Role hard gates are deliberately bounded: `speaker_role` must be `USER`, the
reaction/action must be user-owned and allowlisted, and declared assistant-only
claim/action matchers must not match. Residual paraphrased role naturalness is
human-owned; Triana does not claim a general semantic classifier without a
judge.

Fact and action gates operate only on versioned declarative matchers. Missing
matchers for a required hard gate invalidate the context before egress rather
than weakening validation.

### 6.1 Echo algorithm

Algorithm `LABS06_ASSISTANT_ECHO_V1`:

1. Unicode NFKC normalize, casefold, replace non-alphanumeric runs with one
   space, trim, and collapse whitespace.
2. Compare the proposed utterance with every prior assistant turn.
3. Equality, or normalized containment whose shorter side has at least twelve
   tokens, is `EXACT_ASSISTANT_ECHO`.
4. Otherwise build ordered contiguous token trigrams. Jaccard similarity at
   or above `0.80` is `NEAR_ASSISTANT_ECHO`.
5. Inputs shorter than three tokens have no near-echo trigrams; declared exact
   matchers and other semantic gates still apply.

The threshold is frozen by positive and negative fixtures. No embedding,
provider, or model judge participates.

## 8. Context-bundle and internal API wire

LABS-06 activates only from an explicit verified local context bundle:

```python
@dataclass(frozen=True)
class SimulatorContextBundle:
    bundle_hash: str
    contexts: tuple[JsonObject, ...]
    teacher_forced_items: tuple[JsonObject, ...]

class SimulatorContextLoader(Protocol):
    def load(self, path: Path) -> SimulatorContextBundle: ...

run(..., simulator_context_bundle: Path | None = None,
    context_loader: SimulatorContextLoader | None = None, ...)

evaluate_teacher_forced(
    context_bundle: Path, *, simulator: SimulatorBoundary,
    context_loader: SimulatorContextLoader | None = None,
) -> Mapping[str, bytes]
```

The default loader accepts one regular non-symlink canonical JSON file with a
single trailing LF and maximum size 1 MiB. An injected loader replaces only
read, schema, and identity verification. A call without a bundle retains
historical LABS-05 behavior. A supplied valid bundle selects LABS-06; a
supplied invalid bundle is `SIMULATOR_CONTEXT_INVALID` and never falls back.
No CLI or config-schema surface is added in this slice.

The closed bundle has exactly `artifact_kind` =
`labs06_simulator_context_bundle`, `schema_version` = 1,
`protocol_version`, `source_case_set_hash`, `source_policy_selection_hash`,
`panel_identity_hash`, three ordered `contexts`, thirty ordered
`teacher_forced_items`, and `bundle_hash`. The bundle hash is SHA-256 over
canonical JSON excluding that field. Context and item IDs use their declared
prefix plus the first sixteen hexadecimal characters of their canonical
identity hash. `panel_identity_hash` hashes the ordered item identities.

Each context contains source identities, persona, intent, known facts,
controller-only hidden IDs and literal matchers, user-owned policy, initial
state, reaction/action/stop registries, assistant-only and fixed-fact literal
matchers, and a complete next state for every reaction. Matchers are
normalized literal substrings, never regular expressions. Each teacher-forced
item contains item ID, stratum, context ID, turn index, transcript, latest
observation, interaction state, allowed reaction/action/stop authority, and
remaining turns. The panel is exactly twenty-four ordinary items and one each
angry, impatient, skeptical, informal, mistaken, and adversarial.

`evaluate_teacher_forced` performs exactly one simulator call per item, with
no retry, and returns exactly `fidelity_attempts.jsonl`,
`human_fidelity_review.json`, and `fidelity_manifest.json`. Attempt rows carry
ordered identities, `EMITTED | STOPPED | REJECTED`, proposal or typed detail
codes, hashes, accounting, and reason. The review carries rubric
`REGULAR_USER_SIMULATION_FIDELITY_V1`, bundle/panel identities, `PENDING`,
denominator 30, required accepted 24, the frozen critical-code set, stratum
counts, and thirty ordered items with null human fields. The manifest carries
exact counts, accounting, and artifact hashes. This is separate from, and
does not replace or extend, `human_adaptation_review.json`.
